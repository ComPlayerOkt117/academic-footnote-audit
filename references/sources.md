# 母文献与来源核对

## 母文献识别：模型在盘点阶段填写（主路径）

母文献是用户需要提供的整本书、整期期刊、整份报纸或完整档案文件。析出文章、章节或文件是其内部定位信息，不把析出题名误当母文献题名。

**识别母文献身份是语义任务，由模型在盘点阶段完成**，把结果写入每条记录的 `parent_work_title_with_volume_or_part`、`excerpted_work_titles`、`source_type`、`publisher_or_journal`、`publication_year_or_date`、`issue_number`、`author_editor` 等字段。脚本只负责归并、去重、按卷册分列和污染检查，绝不覆盖模型已填写的题名。

**作者/编者判定必须有责任标记证据**：国标式 `作者.题名` 的点号、书名号式 `作者：《题名》` 的冒号、英文 `Author, ed. Title` 的逗号/`ed.`。仅以空格与题名分隔的段（如 `全世界优秀青年代表 一致同情中国人民的解放斗争[N]`）是标题内容而非作者——无责任标记即作者为空，不得臆造。

**题名隐含人名时人名即作者**：《毛泽东选集》《陈云文集》这类书名以人名开头的（人名+选集/文集/文选/全集），作者取该人名（毛泽东、陈云），不得留空，也不得把解释写进"差异/疑点"。

## 文献单元分类：报刊/期刊一文一文献，图书整本为单元

- **图书/专著/文集/讲话单行本（[M]）**：待核文献=整本（含卷册）。文集内的析出篇不单独建项（用户持整本可核任意页）。
- **析出//母文献 的"待核单元"= `//` 之后（或 `载` 之后）的母文献**：如 `刘凤梅.延安日本工农学校[M]//中共中央党史研究室编.中共党史资料 第42辑.北京：中共党史出版社，1992：166.`，用户要去找的是**《中共党史资料 第42辑》整本**，不是刘凤梅那篇。因此清单条目：题名=母文献题名（《中共党史资料 第42辑》），作者/编者=母文献自身的责任者（中共中央党史研究室编），析出作者（刘凤梅）、析出题名（延安日本工农学校）与析出标记符号**一概不出现在待核文献清单的任何列**——它们是脚注原文内部信息，只在逐条清单的"脚注内容"中可见，可另存于 `excerpted_work_titles` 字段供追溯，但不渲染为待核条目或作者。
- **报纸文章（[N]）**：**每一篇文章都是独立待核文献**——核查时找的是该报该期该版该文。条目：题名=文章题名，作者=文章作者（无责任标记则空），报刊名入"出版社/期刊名"栏，日期入"年份/日期"，版号入"期数/版面"。
- **期刊文章（[J]）**：同报纸——每篇文章为独立待核文献（题名=文章题名，刊名入期刊栏，年/期入对应列）。
- **出版社/期刊名只填名称本身**：不含出版地（去掉"北京：""New York:"前缀）、不含译者（去掉"某某，译."段）。
- **"差异/疑点"只记真实差异**：引文与原书/来源的不符、页码疑点等；不得写入盘点阶段的自我决策说明（如"题名已含人名故作者留空"这类解释）。

必须区分不同卷册、分册、辑、期次、日期和档案编号。例如“选编（上）”“选编（下）”“选集第一卷”“选集第二卷”分别建立来源单元。不同卷册即使同属一个丛书系列也各自建项，不合并。

## 引注格式多样性：不依赖 [X] 标记

`[M]`、`[J]`、`[N]` 等类型标记只是 GB/T 国标的一种写法，**许多期刊并不使用**。脚注可能是：

- 国标式：`作者.题名[M].出版地：出版社，年份：页.`
- 书名号式：`作者：《题名》，《书名》，出版地：出版社，年份，第x页`
- “载”字式：`作者：《析出题名》，载《母文献》……`
- 无标记纯文本式、外文式（`Editor, ed. Title: Subtitle. Place: Publisher, Year: p.`）等

模型判定题名时按语义区分作者、题名、出版社、年份、卷册与页码，**不得因没有 `[X]` 就放弃或照抄整条脚注**；书名号《》是中文文献中非常可靠的题名边界。题名不能残留“参见/见/参阅/转引自”等引导词，也不能吞入出版社、年份、页码或项目说明。

## 转引与析出：可核对的母文献 = 转引链末端实际所见文献

脚注可能出现“转引”链，例如：

```text
A. 某篇[N].某报，日期. 转引自 B. 某文[M]//C. ed. 某书. Place: Publisher, Year: p.
```

层级语义如下（**链首在最上游，越往下越接近用户手头能核对的材料**）：

- `转引自` 之后才是可核对的起点。链首（如无法找到原文的某报报道）不作为核对母文献，也不要求用户提供；其内容只留在 `footnote_content` 作背景。
- 若“转引自”之后又出现 `//`，则 `//` 之后是母文献（整本文集/书），`//` 之前是析出文献（收在该文集中的一篇）。
- 例如上例：用于核对的母文献是 `C 编的某书`；`B 的某文` 是该书的析出文献（单独记录在 `excerpted_work_titles`）；`A 的某报报道` 是不可核对的转引来源，不进入母文献清单。
- 中文转引（如“转引自XXX文集，第X卷”且后无 `//`）：直接取“转引自”之后到句末作为母文献，链首丢弃。

`参见 X` 与 `转引自 X` 不同：`参见` 后的 `X` 本身即实际出处，只需剥掉“参见”二字，`X` 整体作为母文献；`转引自` 则需要按上一条处理链首。

### 结构标记不限于 `//` 与 `[M]`：判定是语义任务

`[M]//`、`载《》`、`in:`、`ed.` 只是常见著录形态中的几种。不同引用规范（GB/T、中文期刊自定格式、MLA/芝加哥/哈佛式外文）对"析出文献与母文献"的写法可能完全不同，甚至**没有显式标记**。因此：

- **"谁是待核单元（母文献）、谁是析出、责任者是谁"由模型在盘点阶段按语义判定**并写入题名/作者/析出字段——不得假设脚注里一定存在 `//`、`载`、`in` 等任何单一标记。
- 语义判定的通用信号：包含**出版地/出版社/年份/卷册/页码**信息的那一层通常是母文献（书/集）；其内部引用的单篇（文章、书信、回忆录）是析出。用户要去书店/图书馆找的、需要逐页核对的是前者。
- 模型拿不准时标 `待人工补判` 并向用户说明所见结构，而不是自行挑选一层充当母文献。
- `scripts/normalize_sources.py` 只做归并去重与空白兜底：优先采用模型已填字段；某条字段空白时用正则从脚注提取候选，无法高置信识别则标 `待人工补判` 并保留完整脚注原文于 `source_as_cited` 供补判；脚本的候选**不得覆盖**模型已填字段。模型看到 `待人工补判` 时应回看脚注原文重新填写，不得把整条脚注当题名，也不得清空字段伪装通过。

## 材料提供

用户无需自行找页或裁截图。可以把完整来源放入 `02_来源材料`，也可以提供大型文件的绝对路径。运行时要主动说明两种方式和路径填写方法，并检查路径是否可访问。

来源可以分批提供。用户也可以声明某些来源或脚注自行核对；此时记录为 `用户自行核对`，下一次主动询问其核对结果，并更新为 `用户已核对` 或 `已核实`。

## 核对顺序

对每份来源自行检索目录、书名页、卷册、期次和相关页，阅读引文上下文。书籍、报刊和档案的 `原书页码`（source_page_printed）必须以页面图中印刷页码为准——它是核对后回填的真实页码；电子页仅用于内部导航，不展示给作者。

来源缺失只影响对应记录。已有来源足以核对的记录先完成，其余回到 `待来源`。

## 核对标准：按引用类型分层

- **直接引用**（`citation_type=direct`）：逐字对象是引号内**全部**文字——从头引号到闭引号，包括看似引导性的前段；与原文**任何一字差异都必须报告**，不得因差异落在"引导语"位置而放行（反例教训：注52"对坦桑尼亚来说"vs原书"对于坦桑尼亚来说"差"于"字曾被漏报）。引语嵌入作者转述句中不改变其直接引用性质。
- **间接引用**（`citation_type=indirect`）：仅当引文跨度**不含引号**的纯转述才成立；只需原文在语义上支撑转述——找到对应论断、事件或语境所在的文件、段落或区域即视为通过。**跨度含引号对的行不允许标 indirect**（见 boundary.md 类型判定），应标 direct 并按上条逐字核对引号内成分。

判定一条脚注是直接还是间接引用，以盘点阶段已写入的 `citation_type` 为准（判定规则见 boundary.md），核对阶段按对应标准执行，不得擅自放宽。

## 核对遇阻：保留、告知、由用户定夺

核对中发现疑似不符或无法确认时，正确动作只有三个：

1. **保留记录**：状态标 `待人工复核`，在 `issue` 中写清具体疑点（如"标称页码 416 的内容为XX，未见与引文对应的表述"），不删除、不覆盖；
2. **告知用户**：在交付说明中报告该条未能核对成功及疑点，请用户定夺；
3. **停止深入**：不在来源中全书搜索替代出处、不臆测"作者笔误/页码标错"等结论性判断（作者意图属用户职责）、不扩大排查范围。

用户回应后按其说明更新状态与结论，再继续核对其余记录。宁可多留几条"待人工复核"，也不要把核对做成一厢情愿的找错。

## 逐字核对辅助工具（可选）

`scripts/verify_source_quotes.py` 在来源 PDF 中自动完成引句逐字核对，替代手工逐页查找：

```bash
# 探测该 PDF 的页码偏移（印刷页码 = 电子页 − N，各卷/版本不同，务必实测）
python verify_source_quotes.py <来源.pdf> --detect-offset
# 核对引句（可多条；不给 --offset 时自动探测）
python verify_source_quotes.py <来源.pdf> --pages 43-44,55 \
    --quotes "中国苏维埃万岁！" --quotes "中国共产党现在已成为共产国际最优秀、最强大的支部之一"
```

- **传入核对对象**：直接引用传引号内原文（整句逐字）；间接引用（纯转述、无引号）传被转述的核心论断短语。转述框架词（如"高挂/指出"）不逐字比对。
- 自动处理三类 OCR/排版噪声：页码行（含 `-4 3 -` 拆字形态）、书眉行、跨页断行续接（必要时自动剔除新页顶部书眉行重试）。
- **`--mojibake-gbk`**：部分中文 PDF 文本层把 GBK 字节按 Latin-1 输出成乱码（如 `µÚ Ò»` 实为"第一"），开启后自动反转还原（《毛泽东选集》第一卷 1991 电子版即此类）。
- **页码位置不要盲猜**：先渲染一页或用 pdfplumber 坐标看一眼——页码可能在页脚独立行、页首书眉行行首或行尾（毛选1卷在页首书眉行尾）。探测投票容忍全角数字（`５１`）与多位置。
- 未命中只报告最近位置窗口供复核，不做"笔误"类结论。
- 依赖 pdfplumber：**运行前自动自检**——缺失时工具自动 `python -m pip install pdfplumber`（纯 pip 包、无编译）；安装失败会给出手动安装命令与"无库替代路径"（渲染页面 → 多模态模型看图核对）。无需提前手动准备。

## 无文本层 PDF：视觉核对与页码定位

工具仅处理**有文本层**的 PDF（pdfplumber 直接抽取文本）。无文本层的纯扫描件不要自建 OCR 管道（OCR 拆字/错字率高、需容错匹配），优先视觉；本技能不绑定任何单一模型，按能力分层：

| 情况 | 做法 |
|---|---|
| PDF 有文本层 | `verify_source_quotes.py` 探测偏移 + 逐字核对，模型只做裁决/复核 |
| 无文本层 + 模型可看图 | **主路径**：pdftoppm 渲染 → 模型直接读图核对 |
| 无文本层 + 模型无视觉 + 环境有 OCR | 一次性外部 OCR 作辅助（如 Windows 自带 OCR），属兜底 |
| 无文本层 + 模型无视觉 + 无 OCR | 报告用户：建议提供有文本层版本或转人工 |

执行前先探测模型能否读图（渲染一页试读）；能则走视觉，不能则降级。视觉能正确处理拆字（如"强"被错拆）、书眉噪声、跨页断行——这些恰是 OCR 需要自建容错的地方。

### 视觉核对 + 页码定位算法（只看必要页，绝不全书翻看）

1. **抽样探测映射**：渲染正文区少量页（前/中/后各 1–2 页即可，避开封面/前言/目录区），读出每页印刷页码 → `offset = 电子页 − 印刷页码`（正文区通常恒定，但**各书各卷必须实测，不可沿用假设**）。
2. **只去标称页码**：目标电子页 = 脚注标称印刷页码 + offset，只渲染这一页（或跨页引文再加下一页）核对——**不在来源中搜索引文内容本身**（反例教训：曾在整本数百页书中搜引文关键词，属越界排查）。
3. **一次跳转校正**：若该页内容与引文语境不符，读该页实际印刷页码 P，直接跳 `目标电子页 + (标称页码 − P)`。例：预计 p.302 实际翻到 p.296（提前 6 页）→ 直接 +6 页跳转，不翻中间页。
4. **校正后仍不符 → 停止**：报告用户定夺（沿用"核对遇阻三动作"），绝不继续扩大排查。

此算法是纯操作规则，任何能读图的模型皆可执行。
